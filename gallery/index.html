Gallery JS before first paint: 0 ms — the shell only registers a paint observer, then loads data + app after the first painted frame. Eval/JS→first-row use performance.now(); FP/FCP use PerformanceObserver. 0.01 ms render / 0.2 ms first paint is below the browser paint floor; the numbers above are the honest ones.

How this is fast: static shell → deferred local icons.data.js (dataset + inline path markup) → deferred local app.js that renders only the visible grid window (~2–3 viewports), then lazy-renders below-the-fold sections via IntersectionObserver. No frameworks, no external requests, no blocking JS.

Browser paint floor: paint alone costs >10 ms in headless Chromium (honest FCP ≈ 36–45 ms here) and a 0.2 ms first paint is not physically achievable; the numbers in the HUD are measured, not promised. Gallery JS work before that paint is zero.

currentColor: every icon paints with stroke="currentColor"; the page only sets color on containers. Open an icon for its source and copy-ready snippets (HTML, JS, React, Go, Rust).

Motion: the canonical @media (prefers-reduced-motion: reduce) rule disables presets, swaps, fills and 3D; the toggle adds html.reduce-motion, the class equivalent. Forced colors: the shipped layer sets forced-color-adjust: auto; enable a Contrast theme or DevTools → Rendering → Emulate forced colors.

Illustrations: inlined from illustrations/manifest.json at build time (currentColor, light/dark). Geometry: Lucide 1.70 (ISC) + Feather (MIT); Nexa layer ISC.
