# Nexa Icons

> Open-source icon system: 1,015 stroke icons in 24 categories, shipped as
> tree-shakeable React/TypeScript, zero-dependency JavaScript, HTML sprites,
> Go and Rust packages. Every icon is currentColor-only, theme-safe, and can
> optionally use shapes, outline/duotone/solid fill, semantic animations,
> swap/morph, frosted glass + gradient effects and CSS-3D presets.

## Live gallery
- [Icon gallery](https://ramanasai.github.io/nexa-icons/): search, categories, shape/fill/3D/glass demos, copy-ready snippets for HTML, JS, React, Go and Rust.

## Installation
- npm / Yarn / pnpm / bun: `npm install @nexa/icons` (developers can also use `npm ci && npm test`)
- React: `import { Bell } from "@nexa/icons"` (+ optional `@nexa/icons/animations.css`)
- JavaScript (zero dependencies): `import { svg, sprite } from "@nexa/icons/js"`
- HTML: inline `sprite.svg`, then `<svg><use href="#nexa-bell"/></svg>`
- Go: `import nexaicons "github.com/nexa-icons/nexa/go"`
- Rust: `use nexa_icons::{get, SvgOptions};`
- Rust + GPUI: crate `nexa-icons-gpui` in `rust/gpui/`

## Quick facts
- 1,015 icons, 24 categories, 26 swap pairs (49 directed edges).
- Defaults: 24×24 grid, 24 px, stroke 1.5; size→stroke 16→2, 20→1.75, 24+→1.5.
- One tree-shaken React icon: ~1,544 B brotli (React external).
- No runtime dependencies for the JS path; React is an optional peer.
- 90/90 tests, release budgets and docs checks pass; gallery verified in Chromium and WebKit.
- License: ISC; icon geometry derives from Lucide 1.70 (ISC) and Feather (MIT), attribution in NOTICE.
