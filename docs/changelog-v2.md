# Nexa Icons 2.0 — changelog (pre-release)

## alpha.1 — design system foundation

- Added the Nexa 2.0 design audit and geometry specification.
- Added 20 hand-authored representative icons with outline, solid and duotone
  variants and optical 16/20/24/32/48 previews.
- Added old-vs-new comparison sheets and contact sheets.
- Added `design:build` and `design:qa` tooling.
- Added the Nexa 2.0 Studio prototype (`gallery/v2.html`).
- Refined gallery card proportions, label contrast and independent preview
  controls; glass is now opt-in and no longer required to see an icon.
- No shipping catalog changes and no public API breaks in this alpha.
